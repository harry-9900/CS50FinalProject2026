## About the Project

DWS LEARN is a Chrome Extension that I built to make finding and learning programming skills easier.

While learning web development and exploring different areas of technology, I noticed that learning resources are spread across many websites. Sometimes it takes extra time to find the right tutorials, courses, and documentation for a particular skill.

I wanted to make this process a little easier, so I created DWS LEARN.

With this extension, users can search for different technical skills, explore their categories, check their difficulty levels, and quickly find useful learning resources from different platforms.

## Features

- **Skill Search:** Search for a programming language, framework, tool, or technology.
- **Category Filter:** Browse skills by categories such as Web Dev, Data Science, Cyber Security, AI/ML, Cloud, and more.
- **Difficulty Levels:** See whether a skill is Beginner, Intermediate, or Advanced.
- **Learning Resources:** Find links to tutorials, documentation, and courses.
- **Quick Access:** Open learning platforms directly from the extension.
- **Dark/Light Mode:** Switch between light and dark themes.
- **Simple Interface:** A clean and lightweight design that is easy to use.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Font Awesome
- Chrome Extension API (Manifest V3)

## Project Files

- `manifest.json` — Extension configuration.
- `popup.html` — Main extension interface.
- `style.css` — Custom styling.
- `data.js` — Skill information and learning resources.
- `script.js` — Search, filtering, and theme functionality.
- `run.js` — Additional JavaScript functionality.

## Installation

To try DWS LEARN on your computer, follow these steps:

1. Clone this repository:

   ```bash
   git clone https://github.com/harry-9900/dws-learn.git
   ```

2. Open Google Chrome.
3. Go to `chrome://extensions/`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the downloaded project folder.

The extension should now appear in your Chrome extensions list.
